# APIレスポンス設計

## 正常系

- HTTP ステータスは取得・更新で 200、登録で 201 とする。リダイレクトは 302、キャッシュ利用は 304 とする。
- 返却項目は各 API の IF仕様書で定義する。複数件は配列とする。
- NULL 項目は返却しない。

## 準正常系・異常系

エラー時は `code` を必ず返す。バリデーションエラーのときだけ `details` を付ける。

- スタックトレース、SQL、例外内容などの内部情報は含めない。

### エラーコード一覧

| コード                  | HTTP ステータス | 説明                                                   | ログID              |
| ----------------------- | --------------- | ------------------------------------------------------ | ------------------- |
| VALIDATION_ERROR        | 400             | バリデーションエラー                                   | L1101, L1102〜L1104 |
| AUTHENTICATION_ERROR    | 401             | 認証エラー（トークン不正・期限切れ・未指定）           | L2004               |
| PERMISSION_DENIED       | 403             | 権限エラー（認証済みだが対象リソースの操作権限がない） | L2006               |
| FOREIGN_ACCESS_ERROR    | 403             | 海外アクセス（WAF 側で返す。アプリでは使用しない）     | -                   |
| RESOURCE_NOT_FOUND      | 404             | リソースが存在しない                                   | L1202               |
| ENDPOINT_NOT_FOUND      | 404             | エンドポイントが存在しない                             | L2002               |
| METHOD_NOT_ALLOWED      | 405             | 許可されていないメソッド                               | L2003               |
| RESOURCE_ALREADY_EXISTS | 409             | リソースが登録済み                                     | L1213               |
| UNSUPPORTED_MEDIA_TYPE  | 415             | リクエストの `Content-Type` が非対応                   | L1101               |
| LOCK_ERROR              | 423             | ロック取得エラー                                       | L1211               |
| INTERNAL_SERVER_ERROR   | 500             | システムエラー                                         | L1003, L1212        |
| UNDER_MAINTENANCE       | 503             | メンテナンス中（WAF 側で返す。アプリでは使用しない）   | -                   |

### バリデーションエラー

`VALIDATION_ERROR` のときだけ、`details` にエラーとなった項目ごとの内容を返す。

```json
{
  "code": "VALIDATION_ERROR",
  "details": {
    "displayName": {
      "code": "REQUIRED",
      "message": "displayNameが設定されていません"
    }
  }
}
```

- `details` は map とする。key はエラーとなったリクエスト項目名とする。
- value には、エラー種別を表す `code` と、項目名を含むエラーメッセージ `message` を設定する。

#### バリデーションエラーコード

| code                    | 種別         | メッセージ                                         | ログID |
| ----------------------- | ------------ | -------------------------------------------------- | ------ |
| REQUIRED                | 必須エラー   | \{項目名\}が設定されていません                     | L1102  |
| REQUIRED_ANY_OF         | 必須エラー   | \{項目名A\}と\{項目名B\}のいずれかの入力が必要です | L1102  |
| INVALID_LENGTH          | 桁数エラー   | \{項目名\}の桁数が正しくありません                 | L1103  |
| INVALID_RANGE           | 範囲エラー   | \{項目名\}の範囲が正しくありません                 | L1103  |
| INVALID_CHARACTER_TYPE  | 形式エラー   | \{項目名\}の文字種が正しくありません               | L1104  |
| INVALID_FORMAT          | 形式エラー   | \{項目名\}の形式が正しくありません                 | L1104  |
| INVALID_VALUE           | 形式エラー   | \{項目名\}に指定できない値が設定されています       | L1104  |
| INVALID_PERIOD          | 期間エラー   | \{項目名\}の期間が正しくありません                 | L1104  |
| FUTURE_DATE_NOT_ALLOWED | 未来日エラー | \{項目名\}に未来日は設定できません                 | L1104  |
| PAST_DATE_NOT_ALLOWED   | 過去日エラー | \{項目名\}に過去日は設定できません                 | L1104  |

- 項目ごとに、該当するログ ID を出力する。リクエストの形式自体が不正（JSON として解析できない場合など）は L1101 を出力する。
