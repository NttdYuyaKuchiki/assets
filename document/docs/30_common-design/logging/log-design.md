# ログ設計

## ログフォーマット

- 下記項目をJSONで出力する。
- 改行コードは`<n>`、タブは`<t>`で置換して出力する。
- 表示する値がない場合は、「-」とする。

| 項目           | 名称       | 説明                                                                                                 |
| -------------- | ---------- | ---------------------------------------------------------------------------------------------------- |
| ログ出力日時   | `time`     | ログの出力された日時を記載。ISO-8601形式（`yyyy-MM-dd'T'HH:mm:ss.SSSXXX`）。                         |
| ログレベル     | `level`    | [ログレベル](#ログレベル)で定義したログレベルを記載。                                                |
| ログID         | `log_id`   | ログ種別を一意に特定するログIDを記載。各ログIDの定義やログの詳細は[ログ一覧](log-catalog.md)を参照。 |
| 機能ID         | `func_id`  | 機能を一意に特定する機能IDを記載。特定できない場合は`unknown`と記載。                                |
| メッセージ     | `message`  | 出力内容本文を記載。                                                                                 |
| 出力箇所情報   | `code`     | 出力箇所に関する情報を記載。内容は[code配下](#code配下)を参照。                                      |
| リクエストID   | `trace_id` | リクエストを識別する値を記載。呼び出しごとに一意となる。UUID形式。                                   |

## code配下

| 項目         | 名称        | 説明                         |
| ------------ | ----------- | ---------------------------- |
| ファイルパス | `file_path` | 出力箇所のパスを記載。       |
| 関数         | `function`  | 出力箇所のメソッド名を記載。 |
| 行番号       | `line_no`   | 出力箇所の行番号を記載。     |

## ログ出力例

```JSON
{
    "time": "2026-04-02T11:44:37.836+09:00",
    "level": "INFO",
    "log_id": "L1001",
    "func_id": "A000000",
    "message": "メッセージ",
    "code": {
        "file_path": "xxx/yyy.py",
        "function": "zzz",
        "line_no": "135"
    },
    "trace_id": "7b2f1de1-6929-49fc-83a8-25d799a39ab7"
}
```

## ログレベル

| レベル | 説明                                                                                                                   | ローカル | 開発 | 検証 | 性能 | STG | 商用 |
| ------ | ---------------------------------------------------------------------------------------------------------------------- | -------- | ---- | ---- | ---- | --- | ---- |
| ERROR  | 想定外のエラー事象のログ。ユーザーエクスペリエンスに影響する致命的なエラー情報を把握する。                             | ●        | ●    | ●    | ●    | ●   | ●    |
| WARN   | ユーザー操作起因による準正常系のログ。ユーザーエクスペリエンスに影響しないエラー情報を把握する。                       | ●        | ●    | ●    | ●    | ●   | ●    |
| INFO   | 運用監視や業務処理の把握に必要な情報を記録する。ユーザ主導またはシステム固有のアクションを記録して利用状況を把握する。 | ●        | ●    | ●    | ●    | ●   | ●    |
| DEBUG  | 開発時のデバッグに使用するログ。障害対応時のみ出力できるようにしておく。                                               | ●        |      |      |      |     |      |
