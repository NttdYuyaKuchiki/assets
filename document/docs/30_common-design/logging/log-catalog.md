# ログID採番ルール

左から

- 1桁目：L固定
- 2〜3桁目：種別を定義
  - 1000番台：共通（サブカテゴリとして100刻みで細分化する）
    - 1000：共通
    - 1100：バリデーション
    - 1200：DB
    - 1300：ファイル
    - 1400：対向システム
    - 1500：AWS
  - 2000：API
  - 3000：バッチ
  - 4000：画面
  - 5000：アプリ
- 数字部は4桁固定（例：L1001）
- 他：種別内で重複しない任意の番号とする
