# ログマスク

## 基本方針

- 認証情報と個人情報は、ログに平文で出力しない。
- マスクはログを出力する共通処理で行う。各機能で個別にマスクしない。
- 判断に迷う項目は、出力しない・マスクする側に倒す。

## マスク対象

| 区分     | 項目                                                            | 扱い       |
| -------- | --------------------------------------------------------------- | ---------- |
| 認証情報 | ID トークン、アクセストークン、リフレッシュトークン、パスワード | 完全マスク |
| 認証情報 | `Authorization`、`Cookie`、`Set-Cookie` ヘッダー                | 完全マスク |
| 識別子   | Cognito の `sub`                                                | 完全マスク |
| 個人情報 | メールアドレス、表示名、氏名、電話番号、住所                    | 完全マスク |

- 上の表に無い項目は、個人情報や認証情報にあたるか確認してから対象に加える。

## マスク方法

| 方法       | 出力例   | 説明                                       |
| ---------- | -------- | ------------------------------------------ |
| 完全マスク | `******` | 値の長さによらず固定の文字列に置き換える。 |

- 元の値の長さが分かる形（桁数に合わせた伏せ字）にはしない。
- 値は伏せても、キーは残す。項目の有無をログから確認できるようにする。

## ログごとの適用

| ログID                                 | 対象                                                                                                     |
| -------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| L2001 アクセスログ                     | `request.headers`、`request.body`、`request.query`、`response.headers`、`response.body` のマスク対象項目 |
| L1201 クエリ                           | バインド前の SQL を出力する。バインドする値は出力しない                                                  |
| L1401/L1402 対向リクエスト・レスポンス | `headers`、`body` のマスク対象項目                                                                       |
| L1003/L1212 例外                       | 例外内容にマスク対象の値が含まれないことを確認する                                                       |

## 禁止事項

- マスク対象の値を、デバッグ用途であってもログに出力しない。
- マスク前の値を一時的にでもファイルに書き出さない。
